# Юнит-тесты для Composable-функций

Эта директория содержит юнит-тесты для composable-функций, которые инкапсулируют и переиспользуют логику состояния в приложении.

## Описание тестов

### `useFieldVisibility.test.js`

Тестирует composable `useFieldVisibility`, который определяет, какие поля должны быть видимы на различных страницах (например, `serviceData`, `contactData`).

-   **Ключевые проверки**:
    -   Корректное определение набора видимых полей для каждой страницы.
    -   Правильная работа функции `checkField`, которая проверяет, должно ли конкретное поле отображаться.
    -   Обработка крайних случаев, таких как отсутствие данных о заказе.

### `useValidationSchema.test.js`

Тестирует composable `useValidationSchema`, который предоставляет схемы валидации для полей форм.

-   **Ключевые проверки**:
    -   Валидация различных полей: `email`, `first_name`, `last_name`, `hours`, `pickup`, `dropoff`.
    -   Проверка на соответствие формату, максимальной длине и другим правилам.
    -   Условная валидация, зависящая от состояния других частей приложения (например, `trustyStore`).
