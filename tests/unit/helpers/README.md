# Вспомогательные утилиты для тестов

Эта директория содержит вспомогательные модули и функции, которые используются для упрощения написания и организации юнит- и интеграционных тестов.

## Описание утилит

### `createTestStore.js`

Предоставляет функции для создания и инициализации тестовых хранилищ Pinia. Это позволяет изолировать состояние для каждого теста и легко мокировать `actions` и `getters`.

### `mockAxios.js`

Содержит утилиты для создания моков `axios`. Это позволяет симулировать ответы API (как успешные, так и с ошибками) без выполнения реальных сетевых запросов.

### `mountComponent.js`

Предоставляет обертку над `mount` из `@vue/test-utils` для упрощения монтирования компонентов с необходимыми плагинами, `props` и моками.
