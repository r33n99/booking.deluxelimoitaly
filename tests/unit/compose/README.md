# Юнит-тесты для Composable-функций (старый подход)

Эта директория содержит юнит-тесты для composable-функций, созданных в рамках более раннего подхода к разработке.

## Описание тестов

### `datePicker.test.js`

Тестирует composable `useDatePicker`, который управляет всей логикой, связанной с выбором даты и времени в приложении.

-   **Ключевые проверки**:
    -   **Инициализация**: Проверка корректной инициализации всех `ref` и функций.
    -   **Обработка данных**: Тестирование функции `handleInternal` на различных входных данных.
    -   **Минимальная дата (`minDate`)**: Проверка логики, определяющей минимальную доступную для выбора дату (сегодня или завтра в зависимости от времени в Риме).
    -   **Минимальное время (`minTime`)**: Тестирование логики расчета минимального времени в зависимости от выбранной даты и текущего времени.
    -   **Опции времени (`timeOptions`)**: Проверка генерации и фильтрации доступных для выбора временных слотов.
