# Юнит-тесты для компонентов

Эта директория содержит юнит-тесты для различных компонентов Vue, сгруппированные по их назначению.

## Структура директории

-   [`features/`](./features/README.md): Тесты для компонентов, реализующих определенные функциональные блоки.
-   [`ui/`](./ui/README.md): Тесты для базовых UI-компонентов, таких как формы и автозаполнение.
