# Юнит-тесты для компонента AutocompleteList

Эта директория содержит юнит-тесты для компонента `AutocompleteList`, который отвечает за отображение выпадающего списка с подсказками для полей ввода.

## Описание тестов

### `AutocompleteList.test.js`

Этот файл содержит тесты, проверяющие различные аспекты работы компонента `AutocompleteList.vue`.

#### Ключевые проверки:

-   **Видимость**:
    -   Проверяет, что список подсказок отображается, когда `openList` имеет значение `true`.
    -   Убеждается, что список скрыт, когда `openList` имеет значение `false`.

-   **Рендеринг**:
    -   Тестирует корректное отображение элементов списка на основе переданных `suggestions`.
    -   Проверяет, что к выбранному элементу применяются соответствующие стили для выделения.

-   **События**:
    -   Убеждается, что при клике на элемент списка генерируется событие `selectSuggestion`.

-   **Обработка данных**:
    -   Проверяет, что компонент корректно обрабатывает пустой массив `suggestions` и не отображает список.

-   **Дочерние компоненты**:
    -   Тесты мокируют дочерние компоненты, такие как `AirportOption` и `HotelOption`, чтобы изолировать и протестировать только логику самого `AutocompleteList`.
