# Юнит-тесты для компонентов форм

Эта директория содержит юнит-тесты для различных UI-компонентов форм.

## Описание тестов

### `OneWayTransferForm.test.js`

Тестирует форму "One Way Transfer".

-   **Ключевые проверки**:
    -   Валидация и отправка формы.
    -   Переключение видимости карты маршрута.
    -   Валидация адресов в странах ЕС.

### `HourlyAsDirectedForm.test.js`

Тестирует форму "Hourly as Directed".

-   **Ключевые проверки**:
    -   Валидация и отправка формы.
    -   Обновление количества часов.
    -   Валидация адресов в странах ЕС.

### `ToursForm.test.js`

Тестирует форму для туров и роуд-шоу.

-   **Ключевые проверки**:
    -   Валидация и отправка формы.
    -   Логика редиректа в зависимости от типа заказа.
    -   Запрос на обновление списка автомобилей при изменении количества пассажиров.

### `RealTimeValidation.test.js`

Тестирует валидацию в реальном времени для различных полей в формах.

-   **Ключевые проверки**:
    -   Обязательные поля.
    -   Максимальная длина полей.
    -   Специальные форматы (email, URL).
    -   Валидация дат.

_Примечание: Тесты для форм "forAgency" были пропущены, так как они в основном повторяют логику обычных форм с добавлением нескольких полей._
