# Юнит-тесты для компонента выбора контактов

Эта директория содержит юнит-тесты для компонента `ContactsChoise`, который отвечает за отображение и выбор ранее введенных контактных данных.

## Описание тестов

### `ContactsChoise.test.js`

Этот файл содержит тесты для компонента `ContactsChoise.vue`.

#### Ключевые проверки:

-   **Отображение данных**:
    -   Проверяет, что имя, фамилия, email и номер телефона последнего использованного контакта корректно отображаются.
    -   Тестирует форматирование номера телефона (добавление `+` к коду страны).

-   **Взаимодействие с пользователем**:
    -   Убеждается, что кнопка "Select Others" отображается.
    -   Проверяет, что при клике на эту кнопку открывается боковая панель для выбора других контактов.

-   **Обработка крайних случаев**:
    -   Тестирует, как компонент ведет себя, если у контакта отсутствует номер телефона.
    -   Проверяет, что компонент не падает, если `lastUsedContact` не определен.

-   **Стили и верстка**:
    -   Убеждается в наличии правильных CSS-классов для стилизации и адаптивной верстки.
