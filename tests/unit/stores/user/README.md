# Юнит-тесты для хранилищ, связанных с пользователем

Эта директория содержит юнит-тесты для хранилищ Pinia, которые управляют состоянием, связанным с данными пользователя.

## Описание тестов

### `contacts.test.js`

Тестирует хранилище `contactsStore`, которое отвечает за управление списком контактов пользователя.

-   **Ключевые проверки**:
    -   Инициализация и восстановление данных из `localStorage`.
    -   Базовые операции: `select`, `fill`.
    -   Поиск контактов (`findContact`).
    -   Форматирование номеров телефонов (`format_phone`).
    -   Добавление новых контактов и обновление существующих (`add`).

### `profile.test.js`

Тестирует хранилище `userStore` в контексте управления профилем пользователя и данными агентства.

-   **Ключевые проверки**:
    -   Инициализация и восстановление данных из `localStorage` и `sessionStorage`.
    -   Computed-свойства: `token`, `isLoggedIn`, `fullName`.
    -   Actions для управления данными пользователя (`fill`, `update`, `preventLogout`) и агентства (`updateAgency`, `resetAgency`).
    -   Взаимодействие с API для загрузки и обновления профиля.

### `registration.test.js`

Тестирует хранилище `registrationStore`, которое управляет процессом регистрации нового пользователя.

-   **Ключевые проверки**:
    -   Инициализация и восстановление данных о шаге регистрации, `hash` и данных формы.
    -   Actions для управления `hash`, данными регистрации и шагами.
    -   Логика роутинга (`handleCheckStep`) для предотвращения "перескакивания" через шаги регистрации.
