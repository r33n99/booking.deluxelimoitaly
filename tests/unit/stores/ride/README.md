# Юнит-тесты для хранилищ, связанных с поездкой

Эта директория содержит юнит-тесты для хранилищ Pinia, которые управляют состоянием, связанным с процессом заказа поездки.

## Описание тестов

### `order.test.js`

Тестирует хранилище `orderStore`, которое является центральным для управления данными текущего заказа.

-   **Ключевые проверки**:
    -   **Инициализация**:
        -   Проверка корректности начального состояния.
        -   Тестирование восстановления данных из `sessionStorage` и `localStorage` при создании хранилища.
    -   **Actions**:
        -   `changeTypeOrder` и `changeHasPhoneStatus`: Проверка изменения состояния и сохранения в `localStorage`.
        -   `update`, `updateOrder`, `updateOrderId`: Тестирование обновления данных заказа и их сохранения в `sessionStorage`.
        -   `updateStorage`, `payment`: Проверка корректности вызовов API для обновления и оплаты заказа.
    -   **Сброс состояния**:
        -   `resetOrderStore`: Тестирование полного сброса состояния хранилища и очистки связанных данных в `storage`.
