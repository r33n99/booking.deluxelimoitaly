# Юнит-тесты для хранилищ Pinia

Эта директория содержит юнит-тесты для хранилищ Pinia, которые отвечают за управление состоянием приложения. Тесты сгруппированы по функциональным областям.

## Структура директории

-   [`data/`](./data): (пусто)
-   [`ride/`](./ride/README.md): Тесты для хранилищ, связанных с процессом заказа поездки.
-   [`user/`](./user/README.md): Тесты для хранилищ, связанных с данными пользователя.
