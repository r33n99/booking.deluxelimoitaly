# Юнит-тесты

В этой директории находятся юнит-тесты, которые проверяют отдельные компоненты, функции и хранилища в изоляции от остальной части приложения.

## Структура директории

-   [`__mocks__/`](./__mocks__): Моки для различных модулей и API.
-   [`components/`](./components/README.md): Юнит-тесты для компонентов Vue.
-   [`composables/`](./composables/README.md): Юнит-тесты для composable-функций.
-   [`compose/`](./compose/README.md): Юнит-тесты для composable-функций (старый подход).
-   [`helpers/`](./helpers/README.md): Вспомогательные утилиты для тестов.
-   [`plugins/`](./plugins/README.md): Юнит-тесты для плагинов Vue.
-   [`router/`](./router/README.md): Юнит-тесты для `vue-router`.
-   [`setup/`](./setup): Конфигурационные файлы для тестов.
-   [`stores/`](./stores/README.md): Юнит-тесты для хранилищ Pinia.
