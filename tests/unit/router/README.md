# Юнит-тесты для роутера

Эта директория содержит юнит-тесты для `vue-router`, проверяющие его конфигурацию и логику, используемую в хуках навигации.

## Описание тестов

### `index.test.js`

Этот файл тестирует статическую конфигурацию роутера.

-   **Ключевые проверки**:
    -   Наличие и правильность всех основных, динамических и специальных маршрутов.
    -   Корректность мета-информации (`title`, `step`) для маршрутов.
    -   Отсутствие дублирующихся путей и имен.
    -   Правильное разрешение маршрутов по имени и пути.

### `navigationGuards.test.js`

Этот файл содержит юнит-тесты для отдельных логических блоков, которые используются внутри хуков навигации (`navigation guards`).

-   **Ключевые проверки**:
    -   Обработка и парсинг `query`-параметров из URL.
    -   Логика определения доступа к страницам (`allowedPages`).
    -   Проверка типа пользователя.
    -   Вспомогательные функции, такие как трансформация формата даты.
