# Юнит-тесты для плагинов

Эта директория содержит юнит-тесты для различных плагинов Vue, которые добавляют глобальную функциональность в приложение.

## Описание тестов

### `storage.test.js`

Тестирует плагин `storage`, который представляет собой обертку над `localStorage` для удобного доступа к данным.

-   **Ключевые проверки**:
    -   Получение нескольких ключей (`getKeys`).
    -   Заполнение объекта данными из `localStorage` (`fillOutKeys`).
    -   Корректная работа базовых методов: `getItem`, `setItem`, `removeItem`.

### `utils.test.js`

Тестирует плагин `utils`, который содержит набор вспомогательных функций.

-   **Ключевые проверки**:
    -   `isEmpty`: Проверка на "пустоту" для различных типов данных.
    -   `dateFormat`: Корректное форматирование дат.
    -   `isLetter` / `isNumber`: Валидация ввода в реальном времени.

### `validPhone.test.js`

Тестирует плагин `validPhone`, который используется для валидации ввода номера телефона в реальном времени.

-   **Ключевые проверки**:
    -   Разрешение ввода только цифр.
    -   Валидация длины номера с использованием мока `libphonenumber-js`.
    -   Корректная обработка префикса страны.
