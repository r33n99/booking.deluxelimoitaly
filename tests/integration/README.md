# Интеграционные тесты

В этой директории находятся интеграционные тесты, которые проверяют взаимодействие между различными частями приложения, такими как компоненты, хранилища Pinia и роутер.

## Структура директории

-   [`authentication/`](./authentication/README.md): Тесты для полного цикла аутентификации пользователя.
-   [`components/`](./components/README.md): Тесты для различных компонентов Vue, сгруппированные по их функциональности.
-   [`ride-history/`](./ride-history/README.md): Тесты для страницы истории поездок и функциональности фильтрации.
-   [`router/`](./router/README.md): Тесты для `vue-router`, проверяющие навигацию и обработку маршрутов.
-   [`vehicle/`](./vehicle/README.md): Тесты для процесса выбора автомобиля и обновления заказа.
