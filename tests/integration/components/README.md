# Интеграционные тесты компонентов

В этой директории содержатся интеграционные тесты для различных компонентов Vue. Тесты сгруппированы по функциональным областям.

## Поддиректории

-   [`forms/`](./forms/README.md): Тесты для компонентов форм, проверяющие их взаимодействие с хранилищами данных и другими компонентами.
