# Интеграционные тесты для компонентов форм

Эта директория содержит интеграционные тесты для различных форм, используемых в приложении. Тесты проверяют взаимодействие компонентов форм с хранилищами Pinia, а также друг с другом.

## Описание тестов

### `FormsIntegration.test.js`

Этот файл содержит общие интеграционные тесты для всех основных форм заказа.

-   **Ключевые проверки**:
    -   Проверка наличия основных элементов (кнопка отправки, поля ввода).
    -   Имитация отправки формы для проверки состояния `isSubmitting`.
    -   Взаимодействие с моками зависимостей, таких как `TrustyComplete`, `RouteMap` и `VueDatePicker`.

### `HourlyAsDirected.test.js`

Тесты для формы "Hourly as Directed" (почасовая аренда).

-   **Ключевые проверки**:
    -   Инициализация и обновление данных заказа в `orderStore`.
    -   Расчет расстояния на основе количества часов.
    -   Валидация адресов в странах ЕС через `trustyStore`.
    -   Сохранение выбранного автомобиля в `carsStore`.

### `OneWayTransfer.test.js`

Тесты для формы "One Way Transfer" (трансфер из точки А в точку Б).

-   **Ключевые проверки**:
    -   Валидация адресов (pickup и dropoff) на принадлежность к странам ЕС.
    -   Интеграция с `AutocompleteList` для отображения и выбора адресов.
    -   Синхронизация данных между `orderStore` и `trustyStore`.

### `ToursRoadshowsIntegration.test.js`

Тесты для формы "Tours & Roadshows" (туры и роуд-шоу).

-   **Ключевые проверки**:
    -   Корректная инициализация формы с необходимыми полями.
    -   Интеграция с `RouteMap` для отображения маршрута.
    -   Обработка и валидация адресов в ЕС.
    -   Взаимодействие с `orderStore` для создания заказа типа "tours".

### `VehiclePage.test.js`

Тесты для логики страницы выбора автомобиля (`VehiclePage`).

-   **Ключевые проверки**:
    -   Получение данных о заказе из `orderStore`.
    -   Загрузка списка доступных автомобилей на основе данных маршрута.
    -   Сохранение списка автомобилей в `carsStore`.
    -   Обновление данных заказа (например, цены) после выбора автомобиля.
    -   Перенаправление на следующую страницу после выбора автомобиля.
