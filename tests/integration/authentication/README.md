# Интеграционные тесты аутентификации

В этой директории содержатся интеграционные тесты, проверяющие полный цикл аутентификации пользователя в приложении.

## Описание тестов

### `AuthenticationFlow.test.js`

Этот файл тестирует весь процесс входа пользователя в систему, начиная от ввода данных и заканчивая обновлением состояния приложения после успешной аутентификации.

#### Ключевые проверки:

-   **Успешная аутентификация**:
    -   Корректный вызов API с учетными данными пользователя.
    -   Обновление состояния пользователя в хранилище Pinia (`userStore`).
    -   Сохранение данных пользователя в `localStorage`.
    -   Перенаправление пользователя на соответствующую страницу после входа.
    -   Отдельно проверяется аутентификация для обычного пользователя и для агентства.

-   **Обработка ошибок**:
    -   Обработка неверных учетных данных.
    -   Обработка сетевых ошибок и ошибок сервера (например, статус 500).
    -   Корректная обработка ошибки "неавторизован" (статус 401).

-   **Выход из системы (Logout)**:
    -   Очистка данных пользователя из `userStore`.
    -   Удаление данных пользователя из `localStorage`.
    -   Перенаправление на страницу входа.
