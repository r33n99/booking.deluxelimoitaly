# Интеграционные тесты истории поездок

В этой директории находятся интеграционные тесты для страницы истории поездок и связанных с ней компонентов.

## Описание тестов

### `RideHistoryFilterIntegration.test.js`

Этот файл тестирует взаимодействие между страницей истории поездок (`RideHistoryPage`) и компонентом фильтрации (`RidesFilter`), а также их интеграцию с хранилищами Pinia.

#### Ключевые проверки:

-   **Загрузка данных**:
    -   Проверяет, что при открытии страницы истории поездок происходит корректный вызов API для загрузки списка поездок.
    -   Убеждается, что полученные данные сохраняются в `historyStore` и отображаются на странице.

-   **Фильтрация поездок**:
    -   Тестирует, что при изменении фильтров (например, по статусу или дате) API вызывается с правильными параметрами фильтрации.
    -   Проверяет, что на странице отображаются только те поездки, которые соответствуют выбранным критериям фильтра.

-   **Сортировка**:
    -   Проверяет, что функциональность сортировки (например, по дате) работает корректно и отправляет правильные параметры в API.

-   **Взаимодействие с хранилищами**:
    -   Убеждается в правильном взаимодействии с `historyStore` для управления состоянием истории поездок.
    -   Проверяет, что `userStore` используется для аутентификации запросов к API.
