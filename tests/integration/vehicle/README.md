# Интеграционные тесты выбора автомобиля

Эта директория содержит интеграционные тесты, проверяющие процесс выбора автомобиля и его влияние на состояние заказа.

## Описание тестов

### `VehicleSelection.test.js`

Этот файл тестирует полный цикл выбора автомобиля, от загрузки списка доступных машин до обновления данных заказа и отправки их на сервер.

#### Ключевые проверки:

-   **Инициализация состояния**:
    -   Убеждается, что хранилища (`carsStore`, `orderStore`, `userStore`) корректно инициализируются с необходимыми для теста данными.

-   **Интеграция хранилищ (`carsStore` и `orderStore`)**:
    -   Проверяет, что выбор автомобиля в `carsStore` корректно обновляет данные в `orderStore` (например, `orderData.car` и `orderData.total`).

-   **Расчет стоимости**:
    -   Тестирует правильность расчета итоговой стоимости поездки на основе базовой цены автомобиля, цены за километр и расстояния поездки.

-   **Сохранение в `sessionStorage`**:
    -   Проверяет, что данные о доступных автомобилях и информация о выбранном автомобиле сохраняются в `sessionStorage` для персистентности между перезагрузками страницы.

-   **Отправка данных на сервер**:
    -   Убеждается, что после выбора автомобиля и обновления заказа, итоговые данные корректно отправляются на сервер через API.
