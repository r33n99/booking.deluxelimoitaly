# Интеграционные тесты роутера

Эта директория содержит интеграционные тесты для `vue-router`, проверяющие его конфигурацию и поведение в приложении.

## Описание тестов

### `routeIntegration.test.js`

Этот файл тестирует основные функции и конфигурацию роутера, чтобы убедиться, что навигация и обработка маршрутов работают корректно.

#### Ключевые проверки:

-   **Основная навигация**:
    -   Проверка корректного отображения компонентов для базовых маршрутов.
    -   Тестирование программной навигации между страницами (`router.push`).

-   **Динамические и Query параметры**:
    -   Проверка обработки динамических сегментов в URL (например, `/password/reset/:hash`).
    -   Тестирование корректного считывания query-параметров из URL (например, `?ssid=...`).

-   **Мета-информация**:
    -   Убеждается, что мета-данные маршрутов (например, `meta.title`) установлены и доступны.

-   **Хуки навигации (Navigation Guards)**:
    -   Проверяет, что глобальные хуки, такие как `beforeEach` и `afterEach`, вызываются при переходах между страницами.

-   **Обработка ошибок**:
    -   Тестирование поведения роутера при попытке перехода на несуществующий маршрут.

-   **Ленивая загрузка (Lazy Loading)**:
    -   Проверяет, что асинхронные компоненты для маршрутов загружаются корректно.
